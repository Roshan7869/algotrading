# Live Trading Configurations

Production and dry-run trading configurations with exchange credentials, stake amounts, pair lists, and risk parameters.

## Config Types
- `config_dry.json` — Paper trading (simulated balance)
- `config_live.json` — Real money trading
- `config_sandbox.json` — Exchange sandbox mode

## Trigger Phrases
- "switch to live config", "use dry run config"
- "configure live trading", "update exchange keys"
