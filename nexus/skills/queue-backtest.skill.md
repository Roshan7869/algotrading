# Queue Backtest

Queue-based backtesting system for batch processing multiple strategy/config/pair combinations sequentially.

## Capabilities
- Multi-strategy batch backtesting
- Config matrix (multiple config files)
- Pair list variations
- Automatic result aggregation
- Parallel worker support

## Trigger Phrases
- "queue backtest", "batch test strategies"
- "run strategy matrix", "schedule backtest"
