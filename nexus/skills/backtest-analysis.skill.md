# Backtest Analysis

Analyzes backtest results with comprehensive metrics, comparison tables, and exportable reports.

## Capabilities
- Result parsing from Freqtrade backtest output
- Strategy comparison across multiple backtest runs
- Parameter sensitivity analysis
- Walkforward analysis reports
- Export to CSV/JSON/HTML

## Trigger Phrases
- "analyze backtest results", "compare backtest runs"
- "generate backtest report", "export results"
