# Trading Agents CLI

Command-line interface for managing and interacting with AI trading agents.

## Commands
- `agents list` — List all registered agents
- `agents run <name>` — Run specific agent
- `agents status` — Show agent health and status
- `agents logs` — View agent execution logs
- `agents config` — Edit agent configurations

## Trigger Phrases
- "list agents", "run agent", "check agent status"
- "view agent logs", "configure agents"
