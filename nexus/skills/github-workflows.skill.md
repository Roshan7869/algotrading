# GitHub Workflows

GitHub Actions workflows for CI/CD, testing, and deployment automation.

## Workflows
- `test.yml` — Run test suite on PR/push
- `lint.yml` — Code quality checks
- `deploy.yml` — Deploy to production
- `security-scan.yml` — Vulnerability scanning
- `backtest-schedule.yml` — Scheduled batch backtests

## Trigger Phrases
- "run CI pipeline", "check workflow status"
- "update GitHub Actions", "add new workflow"
