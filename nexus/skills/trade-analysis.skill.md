# Trade Analysis

Real-time and historical trade analysis: P&L tracking, performance metrics, and risk attribution.

## Capabilities
- Per-trade P&L breakdown
- Strategy-level performance attribution
- Daily/weekly/monthly return aggregation
- Drawdown analysis
- Risk-adjusted return metrics (Sharpe, Sortino, Calmar)

## Trigger Phrases
- "analyze trades", "show P&L breakdown"
- "check performance metrics", "trade attribution"
