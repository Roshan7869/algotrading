# Freqtrade Plots

Visualization subsystem generating trade plots, performance charts, and strategy analysis graphs.

## Capabilities
- Equity curve plots
- Drawdown visualization
- Trade entry/exit markers on price charts
- Profit distribution histograms
- Monthly/weekly return heatmaps
- Indicator overlay charts

## Trigger Phrases
- "plot equity curve", "show trade chart"
- "visualize performance", "generate report plot"
