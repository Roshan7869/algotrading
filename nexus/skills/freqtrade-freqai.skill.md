# Freqtrade FreqAI

FreqAI integrates machine learning into Freqtrade: model training, feature engineering, and prediction-driven trading signals.

## Capabilities
- ML model training with configurable feature sets
- Label engineering for classification/regression targets
- Feature normalization and dimensionality reduction
- Live prediction inference during trading
- Model retraining schedules

## Trigger Phrases
- "train freqai model", "check model accuracy"
- "update feature set", "retrain predictions"
