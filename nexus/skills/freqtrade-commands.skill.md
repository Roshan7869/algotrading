# Freqtrade Commands

Command-line interface for Freqtrade operations: trading, backtesting, hyperoptimization, and data management.

## Available Commands
- `freqtrade trade` — Start live/dry-run trading
- `freqtrade backtesting` — Run backtests with historical data
- `freqtrade hyperopt` — Hyperparameter optimization
- `freqtrade download-data` — Download exchange market data
- `freqtrade list-strategies` — List available strategies
- `freqtrade list-pairs` — List available trading pairs
- `freqtrade test-pairlist` — Test pair list configuration

## Trigger Phrases
- "run backtest", "start hyperopt", "download market data"
- "list strategies", "list pairs"
