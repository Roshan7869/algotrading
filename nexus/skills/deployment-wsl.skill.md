# WSL Deployment

Deployment guide and automation for running the trading system on Windows Subsystem for Linux (WSL2).

## Steps
1. Docker Desktop WSL2 backend
2. Clone repository in WSL filesystem
3. Configure exchange API keys
4. Launch with docker-compose --profile full
5. Access Streamlit UI at localhost:8501
