# Algotrading

Freqtrade-based algorithmic trading platform with AI agent orchestration, MCP data layer, ChromaDB learning loop, and enforced risk management.

## Capabilities
- Multi-strategy trading via Freqtrade (27+ strategies)
- AI agent swarm (TradingAgents, MiroShark, market regime analyzers)
- Redis signal bus for real-time pub/sub
- ChromaDB learning loop (592 vectors, pre-trade similarity queries)
- Enforced circuit breaker with 5 RiskTiers
- Streamlit Bloomberg-inspired UI (9 pages)
- Custom MCP finance data server (10 tools)
- Walkforward backtesting with robustness checks

## Trigger Phrases
- "run the trading bot", "check trading status", "update strategy"
- "show me current positions", "what is the system state"
