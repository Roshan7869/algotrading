# Trading Agents

Autonomous AI trading agents that analyze markets, generate signals, and make trading decisions using LLMs and ML models.

## Agent Types
- Market regime classifier (trending/ranging/volatile/reversal)
- Sentiment analyzer (news + social media)
- Risk assessor (position sizing, drawdown limits)
- Signal validator (cross-check signals before execution)
- Portfolio optimizer (allocation rebalancing)

- "run AI agents", "check agent decisions"
- "review agent recommendations"
