# Multi-LLM Trading Agents

Heterogeneous agent system using multiple LLM providers (DeepSeek, Qwen, Claude) for diversified signal generation and consensus-based decision making.

## Architecture
- Each LLM provider runs independent market analysis
- Signals compared and weighted by historical accuracy
- Consensus threshold required for trade execution
- Provider rotation for bias reduction

## Trigger Phrases
- "run multi-llm analysis", "check llm consensus"
- "compare model signals", "evaluate provider accuracy"
